## 🚀 Easy 3-Step Setup Guide (GitHub & Shopify Sync)

### Step 1: Push this code to your GitHub Repository
Create a new repository named `escape-clothing-17` on your GitHub account, assign the default branch as `main`, and push this code content directly there.

### Step 2: Link GitHub to Shopify Theme Library
1. Log in to your **Shopify Admin Dashboard**.
2. Go to **Online Store &rarr; Themes**.
3. Scroll down to the **Theme Library** section, click **Add Theme**, and select **Connect from GitHub**.
4. Log in to your GitHub account relative to the prompt, select the `escape-clothing-17` repository block, and choose the `main` branch.
5. Click **Connect**!

### Step 3: Publish & Live Customize!
Shopify compiles the assets instantly and populates the theme library with **"Escape Clothing 17 Streetwear Blueprint"**.
1. Click **Customize** to open Shopify's customizer screen.
2. Under the theme editor, you can customize sections like typography, primary color presets (`#050505` background, `#39FF14` neon accent lines), in-store contacts, and banner texts globally.
3. Once satisfied, click **Publish** to make this state-of-the-art dark streetwear layout active for Nagpur’s streetwear culture!
